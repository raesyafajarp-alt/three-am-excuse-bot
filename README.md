A small Node program that writes one line — the most creative excuse a hardware wallet gives for refusing to sign a transaction at 3 AM — to `/output/entry.txt`. Deterministic, no network, no dependencies.

## What it writes

One line, 131 characters, original and written for this competition:

> 3 AM. The fridge hums, your eyes are half-closed, and you want me to sign for a frog coin. I keep a bedtime. You clearly don't. No.

## Run it

```sh
node main.ts
```
